# 🚀 LeetCode SQL 50 Study Plan Solutions

Welcome to my repository for the **LeetCode SQL 50 Study Plan**! This repository contains clean, optimized, and well-structured T-SQL / SQL Server solutions for fundamental to advanced relational database problems.

---

## 📌 Repository Overview

* **Database Engine:** MS SQL Server (T-SQL)
* **Goal:** Master SQL queries, data aggregation, JOINs, Window Functions, CTEs, and query optimization.
* **Topics Covered:** 
  * Select & Basic Joins
  * Basic & Advanced Aggregate Functions
  * Subqueries & Common Table Expressions (CTEs)
  * Advanced String Functions, Regex & Clauses

---

## 🛠️ Key Concepts Applied

* **CTEs & Subqueries:** Modularizing complex logic for readability and performance.
* **Set Operations:** Efficient use of `UNION ALL` over `UNION` to preserve records and maximize performance.
* **Filtering & Ranking:** Leveraging `TOP`, `ORDER BY`, `DENSE_RANK()`, and window functions.
